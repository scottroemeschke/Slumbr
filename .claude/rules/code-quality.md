# Code Quality

- Minimal, surgical changes — don't refactor beyond the task
- YAGNI — don't build for hypothetical requirements
- KISS — simplest solution that works
- One change per commit, one concern per PR
- Never compromise type safety
- Abstractions: consciously constrained, pragmatically parameterised, doggedly documented

Fight entropy. Leave the codebase better than you found it. Every shortcut compounds into technical debt. The patterns you establish will be copied.
